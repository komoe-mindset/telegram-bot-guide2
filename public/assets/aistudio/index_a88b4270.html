Before we begin

မင်္ဂလာပါ၊ စလိုက်ကြမယ် 🌱

တစ်ကြိမ်မှာ တစ်ဆင့်ပဲ လုပ်ပါ။ ပြီးသွားရင် အမှန်ခြစ်လေး ခြစ်ထားနိုင်ပါတယ်။

✿

သင့်ရဲ့ အကူအညီပေးမယ့်သူက AI assistant ပါ

Windows 11 ပေါ်ရှိ Codex၊ Antigravity သို့မဟုတ် သင့် coding assistant ကို attachment ထဲက master prompt ပေးပါ။ ဒီစာမျက်နှာက လမ်းပြဖြစ်ပြီး အလိုအလျောက် install သို့မဟုတ် deploy မလုပ်ပါ။ Assistant ကို repository ရဲ့ AGENTS.md, README.md, PROMPT.md, package.json, wrangler.toml တို့ကို အရင်ဖတ်ခိုင်းပါ။ AGENTS.md ကို ဦးစားပေးရပါမယ်။

🔒လျှို့ဝှက်ချက်များကို ကာကွယ်ပါ။ Token / API key တွေကို ဒီစာမျက်နှာ၊ chat၊ screenshot၊ source file၊ log သို့မဟုတ် command ထဲ မထည့်ပါနဲ့။ Assistant ပေးတဲ့ လုံခြုံသော local input သို့မဟုတ် ယာယီ session environment variable ကို သုံးပါ။

Chapter 01 · Collect your keys

သော့လေး ၃ ခု စုကြမယ် 🔑

အောက်ပါအစီအစဉ်အတိုင်း တစ်ခုချင်း ပြီးအောင်လုပ်ပါ။ သုံးခုလုံး မပြီးမချင်း install / deploy မလုပ်ပါနှင့်။

01
ပထမဆုံး

Telegram bot ဖန်တီးပါ

BOT_TOKEN · သင့် bot ကို ထိန်းချုပ်ဖို့ လျှို့ဝှက်သော့

  1. BotFather ကို Telegram မှာဖွင့်ပါ ↗၊ Start နှိပ်ပြီး /newbot ပို့ပါ။
  2. Bot အမည်ထည့်ပြီး bot နဲ့ဆုံးတဲ့ အသုံးမပြုရသေးသော username တစ်ခု ရွေးပါ။
  3. ရလာသော BOT_TOKEN ကို လျှို့ဝှက်ထားပြီး assistant ရဲ့ လုံခြုံသော local input နည်းလမ်းဖြင့် ပေးပါ။ တန်ဖိုးကို chat ထဲ မပို့ပါနှင့်။
✓ BotFather က token ပေးပြီး လုံခြုံစွာ ထည့်သွင်းပြီးလျှင် နောက်အဆင့်သို့ သွားပါ။ Token တန်ဖိုးကို ပြန်မပြပါနှင့်။
02

Gemini API key ရယူပါ

GEMINI_API_KEY · အသံကို စာသားပြောင်းဖို့ AI ကို အသုံးပြုမယ့်သော့

  1. Google AI Studio ကိုဖွင့်ပါ ↗၊ Google account ဖြင့် sign in ဝင်ပါ။
  2. Create API Key ကိုရွေးပြီး သင့်လျော်သော project ကို ရွေးပါ သို့မဟုတ် အသစ်ဖန်တီးပါ။
  3. ထုတ်ပေးသော key ကို လျှို့ဝှက်ထားပြီး assistant ၏ လုံခြုံသော local input ဖြင့် ထည့်ပါ။
✓ API key ရရှိပြီး လုံခြုံစွာ ထည့်သွင်းပြီးမှ နောက်အဆင့်သို့ သွားပါ။ Deploy မလုပ်ရသေးပါ။
03

Cloudflare ကို ပြင်ဆင်ပါ

CLOUDFLARE_API_TOKEN · bot ကို Worker ပေါ်တင်ဖို့ အသုံးပြုမယ့်သော့

  1. Cloudflare dashboard ကိုဖွင့်ပါ ↗၊ sign in ဝင်ပါ သို့မဟုတ် account ဖန်တီးပါ။
  2. API Tokens နေရာတွင် Workers deployment အတွက် လိုအပ်သည့် အနည်းဆုံး permission များပါသော token ဖန်တီးပါ။ Workers အောက်တွင် workers.dev subdomain ကိုလည်း ပြင်ဆင်ပါ။
  3. Token ကို assistant ထံ လုံခြုံစွာ ပေးပါ။ Account-scoped token ဖြစ်ပါက project ညွှန်ကြားချက်အတိုင်း CLOUDFLARE_ACCOUNT_ID လိုနိုင်ပါတယ်။
✓ သော့ ၃ ခုလုံး အဆင်သင့်ဖြစ်မှ အောက်ပါ installation ကို စပါ။ Cloudflare token သည် deployment credential ဖြစ်ပြီး Worker application secret မဟုတ်ပါ။
Chapter 02 · Bring your bot to life

တည်ဆောက်ပြီး လွှင့်တင်မယ် ☁️

အောက်ပါလုပ်ငန်းများကို AI assistant နှင့်အတူ PowerShell တွင် လုပ်ပါ။

04

ပတ်ဝန်းကျင်ကို စစ်ဆေးပါ

လိုအပ်တဲ့ ကိရိယာတွေ အဆင်သင့်ဖြစ်နေပြီလား?

Assistant ကို repository ကို local တွင် ရှိကြောင်း၊ project လိုအပ်ချက်နှင့် ကိုက်ညီသော Node.js၊ npm၊ PowerShell နှင့် လုံခြုံစွာရရှိနိုင်သော Cloudflare credential တို့ကို စစ်ခိုင်းပါ။ တစ်ခုခုပျောက်နေပါက ပြင်ဆင်ပြီးမှ ဆက်ပါ။

Node.jsProject ကို run ဖို့ လိုတဲ့ runtime
npmProject မှီခိုသော package များ ထည့်သွင်းရန်
05

လိုအပ်တာတွေ ထည့်သွင်းပါ

Dependencies ကို install လုပ်ပြီး Cloudflare ချိတ်ဆက်မှုကို စစ်မယ်

Repository folder အတွင်းမှာ assistant က အောက်ပါ command များကို အစဉ်လိုက် run ပါမယ်။ Dependencies ဆိုတာ project အလုပ်လုပ်ဖို့ လိုအပ်တဲ့ အကူအညီပေး software အစိတ်အပိုင်းလေးတွေပါ။

npm install
npx wrangler whoami
✓ Install အောင်မြင်ပြီး Cloudflare account ကို ပြသနိုင်ရပါမယ်။ Authentication မအောင်မြင်ပါက error ကို assistant နဲ့ ဖြေရှင်းပါ။ Token တန်ဖိုးကို မပြပါနှင့်။
06

Worker ကို deploy လုပ်ပါ

Cloudflare ပေါ်မှာ bot ရဲ့ အလုပ်လုပ်ရာနေရာ ဖန်တီးမယ်

Assistant က deploy လုပ်ပြီး ထွက်လာသော တကယ့် Worker URL ကို မှတ်ထားပါမယ်။ ခန့်မှန်းထားသော URL ကို မသုံးပါနှင့်။

npx wrangler deploy

ထို့နောက် BOT_TOKEN နှင့် GEMINI_API_KEY ကို Cloudflare Worker secrets အဖြစ် လုံခြုံစွာ ထည့်ပါ။ အောက်ပါ command များတွင် တန်ဖိုးကို တိုက်ရိုက် မရေးပါနှင့်။ Assistant ၏ လုံခြုံသော input နည်းကို လိုက်နာပါ။

npx wrangler secret put BOT_TOKEN
npx wrangler secret put GEMINI_API_KEY
✓ Deploy အောင်မြင်ပြီး Worker URL အစစ် ရရှိကာ secrets နှစ်ခု ထည့်ပြီးဖြစ်ရပါမယ်။
07

Telegram နဲ့ ချိတ်ဆက်ပါ

Webhook · Telegram က message ကို Worker ဆီ ပို့ပေးမယ့် လိပ်စာ

Assistant ကို တကယ့် Worker URL နောက်တွင် /webhook ပါသော endpoint ကို Telegram setWebhook API ဖြင့် လုံခြုံစွာ မှတ်ပုံတင်ခိုင်းပါ။ Telegram token ပါသော URL များကို chat၊ log သို့မဟုတ် report တွင် မပြပါနှင့်။

Optional WEBHOOK_SECRET သုံးပါက လုံခြုံစွာ generate လုပ်ပြီး Worker နှင့် Telegram နှစ်ဖက်တွင် တူညီစွာ သတ်မှတ်ရပါမယ်။

ပုံစံသာ ဖြစ်သည်: https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/webhook — အမှန်တကယ် URL ကို deploy output မှ ယူပါ။
Chapter 03 · Check the magic

သုံးချက်စလုံး စစ်ကြမယ် ✨

စမ်းသပ်မှုတစ်ခုခု မအောင်မြင်သေးလျှင် အောင်မြင်ပြီဟု မမှတ်ယူပါနှင့်။

08

Worker နဲ့ webhook ကို စစ်ပါ

လိပ်စာမှန်သလား၊ Telegram က ဆက်သွယ်နိုင်သလား?

  1. Worker health: တကယ့် Worker root URL ကို ဖွင့်ပါ။ HTTP 200 နှင့် project ၏ healthy status message ကို တွေ့ရပါမယ်။
  2. Telegram webhook: Assistant ကို getWebhookInfo လုံခြုံစွာ စစ်ခိုင်းပါ။ Success ဖြစ်ရမည်၊ URL သည် တကယ့် /webhook endpoint နှင့် တူရမည်။ ကျန်ရှိသော updates များ ဖြေရှင်းပြီးနောက် pending_update_count သည် 0 ဖြစ်ရမည်၊ မဖြေရှင်းရသေးသော delivery error မရှိရပါ။
09

Gemini ကို စမ်းပါ

AI က တုံ့ပြန်နိုင်ပြီလား?

တကယ့် Worker URL နောက်မှာ /test-gemini?text=Say%20OK ထည့်ပြီး ဖွင့်ပါ။ HTTP 200 နှင့် OK ရရှိရပါမယ်။

Secrets ထည့်ပြီးချက်ချင်း HTTP 500 ဖြစ်လျှင် ၁၀ စက္ကန့်စောင့်ပြီး တစ်ကြိမ် ပြန်စမ်းပါ။ မအောင်မြင်သေးလျှင် assistant နှင့် တကယ့် error ကို စစ်ဆေးပါ။

Your finishing note

ပြီးသွားရင် report တောင်းပါ 📝

Assistant ကို အမှန်တကယ် စစ်ဆေးထားသော ရလဒ်များဖြင့် Myanmar လို report ပေးခိုင်းပါ။ Voice test မလုပ်ရသေးလျှင် Pending user test ဟု ဖော်ပြရပါမယ်။

  • SUCCESS / FAILED / PARTIAL နှင့် တကယ့် Worker URL၊ webhook URL
  • Webhook registration, pending update count, Worker health နှင့် Gemini test ရလဒ်
  • အတည်ပြုပြီးသော bot username နှင့် မဖြေရှင်းရသေးသည့် ပြဿနာများ
မူရင်း project မှာ ဘာတွေကို ထိန်းသိမ်းရမလဲ?

Bot reply အားလုံး English ဖြစ်ရမည်။ English မဟုတ်သော အသံကို English သို့ ပြောင်းပေးရမည်။ မူရင်း watermark၊ 15 MB audio limit၊ 5-minute duration limit နှင့် message splitting ကို ထိန်းသိမ်းပါ။ Database / VPS မထည့်ပါနှင့်၊ မသက်ဆိုင်သော source code မပြင်ပါနှင့်၊ secret များကို commit မလုပ်ပါနှင့်။ လိုအပ်၍ code သို့မဟုတ် configuration ပြင်လျှင် syntax check၊ redeploy နှင့် test သုံးခုလုံး ပြန်လုပ်ပါ။
